# SehatSaathi marketing assets

Files:

- `sehatsaathi-brochure.html`
- `sehatsaathi-business-card.html`
- `sehatsaathi-poster.html`
- `../distribution/phase-1-distribution-pack.md`

How to use:

1. Open the HTML file in a browser.
2. Replace the QR placeholder with your app link, waitlist form, or demo booking link.
3. Use browser `Print` -> `Save as PDF` for a sendable PDF.
4. Print at 100% scale for best sizing.

Suggested use:

- `sehatsaathi-brochure.html`: A4 brochure for clinics, labs, doctors, investors, or early partners. Founder contact details are already included.
- `sehatsaathi-business-card.html`: A4 founder contact card with Ved's contact details.
- `sehatsaathi-poster.html`: print as an A4/A3 counter poster or standee for labs, pharmacies, gyms, or clinics. Replace the QR placeholder before printing.
- `../distribution/phase-1-distribution-pack.md`: lab pitch, pharmacy pitch, QR flow, first 100-user pilot script, and competitor edge sheet.
